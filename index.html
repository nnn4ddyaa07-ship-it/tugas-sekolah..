🧠 Algoritma Data Siswa

  1. Mulai.
  2. Buka halaman Data Siswa.
  3. Isi data siswa.
  4. Klik tombol Tambah/Simpan.
  5. Sistem memeriksa kelengkapan data.
  6. Jika lengkap, data ditambahkan ke tabel.
  7. Jika tidak lengkap, tampilkan pesan kesalahan.
  8. Selesai.

📝 Pseudocode

BEGIN

INPUT nama
INPUT kelas
INPUT jurusan

IF nama, kelas, dan jurusan tidak kosong THEN
    Tampilkan data ke tabel
ELSE
    Tampilkan pesan "Data belum lengkap"
END IF

END
